# FlowPay Android

Особистий Android-вішліст, трекер цін і фінансовий помічник.

## Цільовий телефон

FlowPay налаштований під **Redmi Note 14** з **Xiaomi HyperOS 3 / Android 16** і дисплеєм **1080 × 2400, 120 Гц**. Застосунок компілюється та таргетує Android 16 (API 36), підтримує обов'язковий edge-to-edge режим і коректні відступи від системних панелей. Мінімальна підтримувана версія — Android 8.0.

## Що вже працює

- додавання товару посиланням із Prom.ua або іншого магазину;
- автоматичне отримання назви, фото та актуальної ціни безпосередньо зі сторінки товару;
- категорії та цільова ціна;
- історія до 90 вимірювань і графік росту/падіння;
- ручне оновлення всього вішліста;
- фонове оновлення через WorkManager кожні 12 годин за наявності інтернету;
- Android-сповіщення про падіння та досягнення цільової ціни;
- калькулятор авансу, зарплати, витрат і доступності вибраного товару;
- USD/UAH за публічним API Monobank;
- регулярні платежі з днем місяця;
- замовлення, трек-номер і статус доставки;
- локальне зберігання даних на телефоні без Android Auto Backup;
- редагування товарів і резервна копія/відновлення даних;
- перевірка та встановлення підписаних оновлень із GitHub Releases.

## Як додати товар

1. Відкрийте вкладку **Бажання**.
2. Натисніть **Додати**.
3. Вставте повне посилання на сторінку товару.
4. За бажанням укажіть цільову ціну та категорію.
5. FlowPay зчитає фото, назву й ціну зі сторінки магазину.

Кнопка **Оновити** перевіряє всі товари одразу. Фонова перевірка працює автоматично.

## Як завантажити APK

Для тестування відкрийте **Actions → Build Android APK → остання зелена збірка → Artifacts → FlowPay-debug-apk**. Усередині ZIP міститься debug APK.

Для звичайного використання встановлюйте підписаний APK зі сторінки **Releases**. Наступні підписані версії можна встановлювати через розділ оновлень самого FlowPay.

## Безпека ключів

API-ключі й ключ підпису не вбудовуються в APK. Дані застосунку виключені із системного Android Auto Backup; ручну резервну копію користувач створює сам у налаштуваннях FlowPay.

Для автоматичної публікації release APK потрібно додати два GitHub Actions secrets:

- `FLOWPAY_KEYSTORE_BASE64` — PKCS#12/JKS-сховище ключа `flowpay`, закодоване Base64;
- `FLOWPAY_KEYSTORE_PASSWORD` — пароль сховища та ключа.

Без цих secrets debug APK продовжує збиратися, а release job показує явне попередження і не публікує непідписаний APK.

## Наступні етапи

- синхронізація між пристроями;
- серверний fallback для магазинів, що блокують пряме зчитування.
